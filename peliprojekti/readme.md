# The Great Museum Mystery
Mohamed Warsame
## Idea

The Great Museum Mystery is a text-based game made with Python. A valuable diamond has been stolen from a museum. The player's job is to find out who stole it.

The player can talk to characters, search rooms, collect items, and find clues. There are four suspects: the security guard, the museum employee, the wealthy visitor, and the technician.

## How to Play

1. Enter your name and age.
2. Start the game.
3. Move around the museum.
4. Talk to characters and search rooms.
5. Collect items and clues.
6. Check your clues.
7. Save or load your game.
8. Accuse the person who stole the diamond.

If you accuse the wrong person, the game ends.

## Functions

The game uses functions to handle different actions, such as talking to characters, searching rooms, moving, collecting items, showing clues, and accusing suspects.

It also has functions to save and load the game.

## Classes

The game has three classes:

- `Player` stores the player's information.
- `Room` stores room information.
- `Item` stores item information.
